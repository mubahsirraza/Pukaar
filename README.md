# Pukaar

**AI-Powered Community Issue Reporting Platform**

Pukaar is a mobile-first civic issue reporting platform that helps citizens report community infrastructure problems using images, descriptions, and location data.

## Project Overview

The system uses multimodal AI to recommend issue categories and severity levels. Administrators review and verify reports before the backend routes them to the responsible departments.

Citizens can track their reports, while the public portal provides privacy-protected maps and community issue analytics.

## Applications

- `mobile/` — Citizen mobile application (React Native + Expo)
- `web/` — Administrator and public web portals (React + Vite)
- `server/` — Backend REST API (Node.js + Express)
- `docs/` — Project documentation

## Technology Stack

- React Native and Expo
- React.js and Tailwind CSS
- Node.js and Express.js
- PostgreSQL and Prisma ORM
- Multimodal AI API
- Cloudinary
- Leaflet and OpenStreetMap
